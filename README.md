# AskSpace · ДЗ4

Сайт вопросов и ответов на Django и PostgreSQL. После входа можно изменить профиль, задать вопрос или ответить на публикацию.

## Запуск через Docker Compose

В папке с `manage.py` создайте файлы окружения командой `python init_env.py`. Если `.env.local` и `.env.docker` уже настроены в ДЗ3, используйте их.

```sh
docker compose up --build -d
```

Откройте [AskSpace](http://127.0.0.1:8000/). Django применит миграции и соберёт статику при запуске. Nginx раздаёт `/static/` и `/media/`. База и загруженные аватары сохраняются в томах Docker. В окружении, где Docker доступен через `sudo`, добавьте его перед командами `docker compose`.

Чтобы добавить демонстрационные публикации и создать администратора:

```sh
docker compose exec web python manage.py fill_db 2
docker compose exec web python manage.py createsuperuser
```

Панель администратора доступна по адресу [`/admin/`](http://127.0.0.1:8000/admin/).

## Запуск Django напрямую

Нужны Python 3.12 или 3.13 и PostgreSQL. Если используете PostgreSQL из Compose, запустите только базу командой `docker compose up -d --wait db`. Для своего сервера укажите параметры подключения в `.env.local`. Конфигурация `.env.example` показывает, какие переменные нужны.

Из папки с `manage.py` в активированном виртуальном окружении выполните:

```sh
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Откройте [`127.0.0.1:8000`](http://127.0.0.1:8000/). При локальном запуске `DJANGO_DEBUG=1` позволяет Django раздавать статику и загруженные аватары. Загрузки сохраняются в `media/avatars/`. Для проверки на своей базе можно выполнить `python manage.py fill_db 2`.

## Публикация вопросов и ответов

Войдите или зарегистрируйтесь. На странице `/ask/` укажите заголовок, текст и до трёх тегов через запятую. После публикации откроется новый вопрос. Ответ добавляется на странице вопроса. После отправки откроется нужная страница списка ответов с переходом к добавленной записи. Профиль и аватар можно изменить на странице `/profile/`.
